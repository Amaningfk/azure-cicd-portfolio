Azure CI/CD, end to end

A complete example: a static site, infrastructure defined twice over in Bicep and Terraform, Kubernetes manifests, and a pipeline that validates every pull request and ships the site on release.

What this demonstrates

  • A validation pipeline that fails on malformed HTML, a missing asset, an infrastructure template that will not compile, or a Kubernetes manifest that does not match the schema.
  • A release pipeline that deploys to Azure Static Web Apps, with the token held in GitHub secrets.
  • Idempotent, tagged infrastructure in both Bicep and Terraform, so a re-run changes nothing and costs stay attributable.
